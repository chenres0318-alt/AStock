# AStock 看盘

面向 A 股盘面的网页看盘工具：指数、自选、分时 / K 线、行业板块、涨跌幅与涨跌停。

红涨绿跌。行情来自腾讯、新浪、东方财富等公开接口，**仅供看盘学习，不构成投资建议**。

## 功能

- 上证、深证、创业板、科创 50、沪深 300、中证 500
- 自选股（本地保存），支持代码 / 名称 / 拼音搜索
- 分时图、日 / 周 / 月 K 线
- 报价、估值、五档盘口、内外盘
- 行业板块、涨幅 / 跌幅 / 成交额、涨停 / 跌停
- 技术选股：板块站上五日线 + MACD 死叉缩绿柱靠近 0 轴 + 5 日均线拐头，再筛成分股（3 日涨幅 ≤ 4%、换手 ≥ 2%）
- 区间回测：2010–2015 与 2020–2026 的日线 T+1 对比（盈亏比 / 收益率 / 最大回撤）
- 交易时段自动刷新（约 5 秒），盘后放慢

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。

```bash
npm run build
npm start
```

首次打开会带一组常见自选；用搜索框加入股票，或按 `/` 聚焦搜索。点击指数、板块领涨股或排行榜即可切到对应标的。顶部「选股」进入技术筛选：先扫行业板块，再在入选板块里挑股票。顶部「回测」查看 2010–2015 / 2020–2026 的策略对比（预计算，不是实时交易）。

重新跑回测（需能访问腾讯行情）：

```bash
python3 scripts/backtest.py
```

## 说明

- 自选列表存在浏览器 `localStorage`，不会上传服务器
- 公开接口偶尔会限流或超时，页面会提示错误，可点「立即刷新」。行业列表优先东财，不可用时回退新浪证监会行业分类；板块指数若无日线，则用成分股均价近似。
- 选股规则按日线计算：站上 5 日均线、5 日均线拐头向上、MACD 死叉（DIF 低于 DEA）且绿柱连续缩短并靠近 0 轴；个股另需近 3 日涨幅 ≤ 4%、换手率 ≥ 2%，并剔除 ST / 北交所
- 回测用腾讯未复权日线、T+1 次日开盘、佣金万 2.5、卖出印花税千 1、滑点万 1。现金分红未计入。结果仅供对照，不是投资建议
- 涨停 / 跌停按主板 10%、创业板 / 科创板 20%、北交所 30%、ST 5% 近似识别
