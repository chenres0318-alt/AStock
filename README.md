# AStock 看盘

面向 A 股盘面的网页看盘工具：指数、自选、分时 / K 线、行业板块、涨跌幅与涨跌停。

红涨绿跌。行情来自腾讯、新浪、东方财富等公开接口，**仅供看盘学习，不构成投资建议**。

## 功能

- 上证、深证、创业板、科创 50、沪深 300、中证 500
- 自选股（本地保存），支持代码 / 名称 / 拼音搜索
- 分时图、日 / 周 / 月 K 线；K 线叠加 5 日均线，并画起涨红丝带。中间价为 (2×收盘+最高+最低+开盘)/5，A1 是 3/6/12/24 日 EMA 的均值，再逐层 EMA(2) 共 7 层。某一层高于前一天画红线，低于前一天画青线。七层刚变成全红，且这根或前 4 根里有过近 5 日首次站上五日线，标买。买入之后，成本是买入价和各次加仓价的等权平均。收盘相对这个成本每下跌 7% 标一次加仓，每上涨 7% 标一次减仓。加仓后按新成本重新分档。减仓之后，要相对上一次减仓收盘再跌超过 8% 才再标加仓，这笔加仓仍计入平均成本。买入之后若 MACD 死叉（DIF 下穿 DEA），标清仓并结束这笔持仓。清仓之后，收盘再次站上五日线且红丝带全红，再标一次买入
- 报价、估值、五档盘口、内外盘
- 行业板块、涨幅 / 跌幅 / 成交额、涨停 / 跌停
- 选股：近 5 日首次站上 5 日均线，且 MACD 多头排列或空头减弱；20 日均线下方的空头减弱只保留大阳 / 大振幅反包。扫描成交额靠前的沪深 A 股（不含 ST / 北交所）
- 交易时段自动刷新（约 5 秒），盘后放慢

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。

```bash
npm run build
npm start
```

首次打开会带一组常见自选；用搜索框加入股票，或按 `/` 聚焦搜索。点击指数、板块领涨股或排行榜即可切到对应标的。顶部「选股」进入首次站上五日线扫描。

## 说明

- 自选列表存在浏览器 `localStorage`，不会上传服务器
- 公开接口偶尔会限流或超时，页面会提示错误，可点「立即刷新」。行业列表优先东财，不可用时回退新浪证监会行业分类
- 选股不再先筛板块。日线规则：当日收盘站上 5 日均线，且近 5 个交易日里这是第一次；同时 MACD 为多头排列（DIF > DEA > 0）或空头减弱（绿柱缩短）。若收盘仍在 20 日均线下方，空头减弱只保留当天涨幅≥5% 或振幅≥8% 的阳线，避免下跌中继里反复轻站五日线。池子取成交额靠前的沪深 A 股，剔除 ST / 北交所。看盘 K 线上的红青丝带和买卖箭头是另一套起涨红丝带，和选股条件不是同一套
- 涨停 / 跌停按主板 10%、创业板 / 科创板 20%、北交所 30%、ST 5% 近似识别
