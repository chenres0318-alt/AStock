# AStock 看盘

面向 A 股盘面的网页看盘工具：指数、自选、分时 / K 线、行业板块、涨跌幅与涨跌停。

红涨绿跌。行情来自腾讯、新浪、东方财富等公开接口，**仅供看盘学习，不构成投资建议**。

## 功能

- 上证、深证、创业板、科创 50、沪深 300、中证 500
- 自选股（本地保存），支持代码 / 名称 / 拼音搜索
- 分时图、日 / 周 / 月 K 线。K 线叠加 4 日（红）、7 日（青）、20 日（黄）收盘均线。日线买点：4 日均线上穿 7 日均线且 MACD 绿柱仍为负但比前一日短，或者空仓后 MACD 绿柱转成红柱。日线卖点：4 日均线下穿 7 日均线，但 4 日均线仍在 20 日均线上方时不卖。周、月线仍是 4 日上穿 7 日且收盘站上 20 日才买，4 日下穿 7 日或收盘跌破 20 日卖。空仓才买，持仓才卖
- 报价、估值、五档盘口、内外盘
- 行业板块、涨幅 / 跌幅 / 成交额、涨停 / 跌停
- 选股：当天收盘 4 日均线上穿 7 日均线，且 MACD 空头势力减弱（绿柱仍为负但缩短）。扫描成交额靠前的沪深 A 股（不含 ST / 北交所）
- 交易时段自动刷新（约 5 秒），盘后放慢

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。

```bash
npm run build
npm start
```

首次打开会带一组常见自选；用搜索框加入股票，或按 `/` 聚焦搜索。点击指数、板块领涨股或排行榜即可切到对应标的。顶部「选股」进入 4 日均线上穿 7 日均线扫描。

## 说明

- 自选列表存在浏览器 `localStorage`，不会上传服务器
- 公开接口偶尔会限流或超时，页面会提示错误，可点「立即刷新」。行业列表优先东财，不可用时回退新浪证监会行业分类
- 选股不再先筛板块。日线规则：当天收盘的 4 日均线从下往上穿过 7 日均线（前一日 4 日均线还不高于 7 日均线），并且 MACD 柱仍小于 0、但大于前一日（绿柱缩短，空头势力减弱）。两条同时成立才入选。池子取成交额靠前的沪深 A 股，剔除 ST / 北交所。日 K 买点在这条之外，空仓后 MACD 绿柱转成红柱也标买。卖点是 4 日下穿 7 日，且当天 4 日均线已经不在 20 日均线上方；4 日均线仍在 20 日均线上方时，这次下穿不卖
- 涨停 / 跌停按主板 10%、创业板 / 科创板 20%、北交所 30%、ST 5% 近似识别
