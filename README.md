# AStock 看盘

面向 A 股盘面的网页看盘工具：指数、自选、分时 / K 线、行业板块、涨跌幅与涨跌停。

红涨绿跌。行情来自腾讯、新浪、东方财富等公开接口，**仅供看盘学习，不构成投资建议**。

## 功能

- 上证、深证、创业板、科创 50、沪深 300、中证 500
- 自选股（本地保存），支持代码 / 名称 / 拼音搜索
- 分时图、日 / 周 / 月 K 线
- 报价、估值、五档盘口、内外盘
- 行业板块、涨幅 / 跌幅 / 成交额、涨停 / 跌停
- 买点选股：按急跌后二次探底不破、底部分量、MACD 绿柱翻头、涨停/大阳打开均线扫描成交额靠前的沪深 A 股（不含 ST / 北交所）
- 回测：对最近一次选股命中的合富中国、博云新材、粤传媒、雪人集团，按同一套买卖点回测 2010–2015 与 2020–2026（胜率、回撤、盈亏比、期望值）
- 交易时段自动刷新（约 5 秒），盘后放慢

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。

```bash
npm run build
npm start
```

首次打开会带一组常见自选；用搜索框加入股票，或按 `/` 聚焦搜索。点击指数、板块领涨股或排行榜即可切到对应标的。顶部「选股」进入买点扫描；「回测」查看这几只命中票在两个历史区间的交易统计。

## 说明

- 自选列表存在浏览器 `localStorage`，不会上传服务器
- 公开接口偶尔会限流或超时，页面会提示错误，可点「立即刷新」。行业列表优先东财，不可用时回退新浪证监会行业分类
- 选股不再先筛板块，也不再限制近 3 日涨幅。日线规则对照哈药股份、有研新材一类买点：急跌回撤后二次探底不破前低，底部分量小于恐慌日，MACD 绿柱缩短后翻头，再用涨停或大阳打开均线确认；启动日成交往往不是阶段天量。池子取成交额靠前的沪深 A 股，剔除 ST / 北交所
- 选股命中票的回测是日线 T+1 模拟，不是实盘。2010–2015 组合亏损；2020–2026 的正期望主要来自少数连板，单笔中位数接近 0。不能外推成稳定月收益
