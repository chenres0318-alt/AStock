# AStock 看盘

面向 A 股盘面的网页看盘工具：指数、自选、分时 / K 线、行业板块、涨跌幅与涨跌停。

红涨绿跌。行情来自腾讯、新浪、东方财富等公开接口，**仅供看盘学习，不构成投资建议**。

## 功能

- 上证、深证、创业板、科创 50、沪深 300、中证 500
- 自选股（本地保存），支持代码 / 名称 / 拼音搜索
- 分时图、日 / 周 / 月 K 线
- 报价、估值、五档盘口、内外盘
- 行业板块、涨幅 / 跌幅 / 成交额、涨停 / 跌停
- 选股：当天 5 日均线拐头向上，此前大部分时间 5 日线向下且股价在 5 日线下方，当日收盘站上 5 日线并放量红柱，换手不低于 2.5%、振幅不低于 2%；扫描成交额靠前的沪深 A 股（不含 ST / 北交所）
- 交易时段自动刷新（约 5 秒），盘后放慢

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。

```bash
npm run build
npm start
```

首次打开会带一组常见自选；用搜索框加入股票，或按 `/` 聚焦搜索。点击指数、板块领涨股或排行榜即可切到对应标的。顶部「选股」进入五日线拐头扫描。

## 说明

- 自选列表存在浏览器 `localStorage`，不会上传服务器
- 公开接口偶尔会限流或超时，页面会提示错误，可点「立即刷新」。行业列表优先东财，不可用时回退新浪证监会行业分类
- 选股不再先筛板块。日线规则：当天 5 日均线拐头向上（昨日 5 日线仍未转升）；此前约 8 个交易日里大部分时间 5 日线向下，且股价多数运行在 5 日线下方；当日收盘站上 5 日线，K 线为放量红柱（阳线且成交量不低于近 5 日均量的 1.2 倍）；换手率不低于 2.5%，振幅不低于 2%。池子取成交额靠前且换手达标的沪深 A 股，剔除 ST / 北交所
- 涨停 / 跌停按主板 10%、创业板 / 科创板 20%、北交所 30%、ST 5% 近似识别
